How it works

  • Downloads of the file types set in LDM's Options go to Last Download Manager instead of the browser.
  • Click the LDM button in the toolbar to turn integration off in that tab (no download capture, no video panel), or on again.
  • Right-click the LDM button and choose Browser integration to turn integration off or on.
  • Last Download Manager does not need to be running: it starts when a download is captured.
